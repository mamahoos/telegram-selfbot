# telegram-voice

Corpus فشرده برای **لحن** — بدون تاریخ، نام، URL.

## فایل‌ها

| فایل | کاربرد | توکن |
|------|--------|------|
| **`voice.compact.txt`** | متن نمونه — `L001\|…` | کم ✅ |
| **`scenario-map.md`** | سناریو A–F → شماره خط؛ **G** = Fallback | کم ✅ |
| `my-messages.txt` | آرشیو با metadata | زیاد — فقط مرجع انسان |

## مسیر برای مدل / LLM

```
profile.md §0           ← شخصیت شناختی (کی هستی)
profile.md §6.1         ← لحن کلی (چطور حرف بزنی)
scenario-map.md         ← تشخیص سناریو A–F؛ اگر نامشخص → §G Fallback
voice.compact.txt       ← خطوط Lxxx (الگو)
cognitive-profile.md  ← §۰ فشرده (اختیاری، کم‌توکن)
```

## سناریوها

| کد | موقعیت |
|----|--------|
| A | utopia / دولت بی‌عمل / تعرفه / اقتصاد |
| B | تاریخ / اصل+اما / مثال موازی |
| C | اتهام چپ / رفع مانع ≠ مداخله |
| D | ضربه‌ای / سؤال / فشار |
| E | موافقت کوتاه |
| F | حقوق فردی / زن / پزشکی |
| G | Fallback — سناریو نامشخص؛ حدس نزدیک‌ترین A–F |
